# 仰望夜空的星辰 内容还原补丁

为 Steam 版[《A Sky Full of Stars 仰望夜空的星辰》](https://store.steampowered.com/app/745960/)还原被移除的剧情内容，同时完整保留 Steam 成就系统与官方中文本地化，还原文本使用 GPT-5.6-sol 翻译。

本补丁仅供已购买正版游戏的用户使用，不包含任何游戏本体文件。

> **当前版本：v1.0.2-beta** — 已通过部分实机验证，仍在测试中。

## 安装方式

提供两种方式，任选其一即可，**不要重复安装**。

### 方式一：安装器（推荐）

从 [Releases](../../releases) 下载 `A_Sky_Full_of_Stars_Content_Restoration_Patch_Installer_vX.X.X.exe`，双击运行。

安装器会依次执行以下步骤：

1. 定位游戏目录（Windows 下会自动检测游戏路径，未找到时可手动输入路径）
2. 列出将被修改的文件，等待确认
3. 就地合并资源并覆盖脚本与文本

安装完成后即可删除安装器。

非 Windows 环境请使用 `tool/pack/` 下的 `install.py`。需要 `arcbuild.py` 与 `payload/` 目录与脚本位于同级。

### 方式二：完整文件覆盖

适合安装器无法运行、或希望自行核对文件的情况。

下载 [`asset/`](./asset) 目录下的全部文件，按原目录结构覆盖到游戏根目录：

```
<游戏目录>/
├── Rio.arc          ← asset/Rio.arc
├── Chip3.arc        ← asset/Chip3.arc
├── Chip3A.arc       ← asset/Chip3A.arc
├── Chip3B.arc       ← asset/Chip3B.arc
├── Graphic.arc      ← asset/Graphic.arc
├── Voice.arc        ← asset/Voice.arc
├── Voice1.arc       ← asset/Voice1.arc
└── zh-CN/
    └── Rio.arc      ← asset/zh-CN/Rio.arc
```

游戏目录一般位于 `<Steam 库>\steamapps\common\A Sky Full of Stars`。

### 两种方式的区别

|  | 安装器 | 完整覆盖 |
|---|---|---|
| 下载体积 | < 1.5 GB | > 3 GB |
| 工作方式 | 读取游戏原文件，就地合并增量 | 直接替换为成品归档 |
| 路径处理 | 自动定位 | 手动放置 |
| 适用场景 | 一般情况 | 安装器不可用、或需自行核对 |

安装器体积更小是因为它只携带增量部分，合并时需要读取游戏现有文件；完整覆盖不依赖原文件，但要下载全部归档。

## 卸载与恢复

补丁**不创建备份**，恢复原版通过 Steam 完成：

1. Steam 库中右键游戏 → 属性
2. 已安装文件 → 验证游戏文件完整性

Steam 会检测出被修改的归档并重新下载，恢复到未安装状态。

## 实现原理

Steam 版（App ID 745960，Build ID 6187244）移除了一部分剧情场景。[已有的还原方案](https://rentry.org/miazorapatch)直接用原版文件覆盖 Steam 文件，但这会引入两个问题：Steam 独有的图层被覆盖后导致运行时报错，成就系统也随之失效。

本补丁采用**增量补充**策略：

- **不替换任何 Steam 已有资源** —— Steam 的高质量素材、成就调用、官方中文全部原样保留
- **只补充 Steam 缺失的内容** —— 18 个剧情脚本、对应 CG 与语音、以及中文文本
- **同名冲突资源做命名空间隔离** —— 少数资源在两版中同名但内容不同，补丁为还原版本另起新名，两套素材并存互不干扰
- **改写跳转指令衔接剧情** —— 在 13 处剧情节点重写跳转目标，让流程从 Steam 主线进入还原内容，播放完毕后再回到 Steam 主线

结果：还原内容可正常进入与播放，中文文本正常显示，成就照常触发。

## 已知情况

### 还原文本来源

还原部分的 34 条中文文本由 **GPT-5.6-sol** 翻译，未经人工校对，风格与用词可能与官方中文存在差异。Steam 原有的 278 条文本保持官方译文不变。

### Steam 版差分的剧情

织姬线的 116、117a 是 Steam 做过改写的场景。这两处涉及的素材（CG、脚本、文本）在两版中名称相同但内容不同，补丁沿用 Steam 版本，但改写了 `117a_E` 的跳转目标，使其在播放完 Steam 剧情后进入紧随其后的还原内容 `117b` → `118_H`。

**最终流程**：`114b_E`(Steam) → `115_H`(还原) → `116_E`(Steam) → `117_E`(Steam) → `117a_E`(Steam) → `117b`(还原) → `118_H`(还原) → `119_E`(Steam)

需要说明的是，`116_E` 和 `117a_E` 引用的 CG `ORI_11S.pna` 在两版中同名但图层构成不同。Steam 将原版的该 CG 挪用并改画，用于配合改写后的剧情。补丁保留 Steam 版 `ORI_11S/L.pna` 和 `ORI_12L.pna`，而还原场景 `115_H` 引用的是命名空间隔离后的 `ORI_90S/L.pna` 和 `ORI_91L.pna`（原版素材另起的新名），两套并存互不干扰。

这种处理让还原内容保持完整，同时 Steam 原有的差分场景也能在其位置正常工作。

### 相同场景沿用 Steam 画面

少数两版共有的场景，Steam 对画面做过调整（表情、姿态的细节改动）。补丁沿用 Steam 版素材，画面可能与原版存在细微差异，不影响剧情理解。这一取舍同时避免了图层错乱与运行时报错。

### CG 鉴赏列表

游戏内可正常观看全部还原场景。但鉴赏（回想）列表的缩略图索引是独立数据结构，本版未扩展，因此 **还原内容的缩略图不会出现在列表中**。这只影响事后回看的入口，不影响初次观看。

### 成就系统

补丁不修改任何 Steam 脚本，成就调用与解锁标记原样保留。

## 目录结构

```
├── asset/              重新封装好的游戏文件（Git LFS）
├── backup/             Steam 原版基线（用于计算增量）
├── doc/                技术文档
├── test_save_files/    供测试使用的游戏存档
├── tool/               通用库和工具
│   ├── install.py      安装器逻辑
│   ├── arcbuild.py     Arc 格式读写库
│   ├── ws2.py          WS2 脚本解码和成就注入
│   ├── arcstream.py    大文件 Arc 流式处理
│   └── lng.py          本地化文本 (.lng) 编解码
├── script/             构建和开发脚本
│   ├── pack.sh         exe 打包脚本
│   ├── generate_payload.py  生成增量补丁
│   ├── final_verification.py 最终验证工具
│   └── icon.ico        打包用图标
├── payload/            增量补丁产物（构建后生成）
├── releases/           exe 最终产物（构建后生成）
└── VERSION             版本号（唯一来源）
```
